# 📈 Regional Sales Comparison Dashboard (Tableau)

## 📝 Project Overview

This project presents a Tableau dashboard built for a leading organization to compare sales performance between two selected regions. The dashboard allows stakeholders to interactively explore key sales metrics and identify areas for improvement.

---

## 📁 Dataset

**Dataset Used**: Sample Superstore (Tableau's built-in dataset)  
**Tool**: Tableau (.twbx workbook)

---

## 🎯 Objective

Enable upper management to:
- Compare key sales metrics between any **two regions**
- Visualize **performance differences**
- Make **data-driven decisions** for business improvements

---

- Tableau Desktop

## ✅ Key Steps Performed

1. **Data Preparation**
   - Selected relevant fields: `Customer Name`, `Order ID`, `Sales`, `Region`, etc.
   - Grouped and organized data using folders for better clarity
   - Created a **Location Hierarchy** based on `Country`

2. **Parameter Creation**
   - Created two dynamic parameters:
     - **Primary Region**
     - **Secondary Region**
   - These allow the user to select and compare any two regions interactively

3. **Calculated Fields**
   - Developed calculated fields to capture:
     - **Primary Region Sales**
     - **Secondary Region Sales**
     - **First Order Date**
     - Other KPI metrics

4. **Dashboard Design**
   - Aligned and partitioned views to display:
     - 📅 First Order Date
     - 💰 Total Sales
     - 📊 Average Sales per Order
     - 👥 Number of Customers
     - 📦 Number of Orders
     - 🛒 Number of Unique Products Sold
   - Ensured a clean, user-friendly layout for side-by-side comparison

---

## 📊 Features of the Dashboard

- **Interactive dropdowns** to choose regions
- **Side-by-side metric comparison**
- **Visuals update instantly** based on user selections
- Focus on **insightful KPIs** to guide decision-making

## 📌 How to Use

1. Open the `Book2.twbx` file using **Tableau Desktop**
2. Use the parameter dropdowns to select **Primary** and **Secondary** regions
3. View real-time comparisons across:
   - Sales
   - Orders
   - Customers
   - Products
4. Explore insights to recommend improvements
